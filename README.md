# Лабораторна робота № 13. Написання тестів з використанням unittest або pytest

## Мета

Здобути практичні навички у написанні модульних тестів (unit tests) для програмного коду на мові Python з використанням стандартної бібліотеки `unittest`. Створити тестові випадки (test cases), використовувати методи перевірки (assertions), організовувати тести в тестові набори (test suites) та запускати їх. Усвідомити важливість тестування в розробці програмного забезпечення та його ролі в забезпеченні якості коду.

## Порядок виконання роботи

1.  **Оберіть варіант завдання** з переліку нижче.
2.  **Реалізуйте функцію або клас** згідно з вашим варіантом у файлі [`src/lab13.py`](src/lab13.py).
3.  **Напишіть модульні тести** для вашої реалізації у файлі [`src/test_lab13.py`](src/test_lab13.py). Тести повинні покривати різні сценарії, включаючи успішне виконання та обробку помилок.
4.  **Запустіть тести** і переконайтесь, що всі вони виконуються успішно. Локально ви можете запустити тести командою:
    ```bash
    python -m unittest discover src
    ```
5.  **Перевірте результати автоматичного тестування.** Після того, як ви надішлете зміни до вашого репозиторію (зробите `git push`), GitHub автоматично запустить тести. Ви можете побачити результат у вкладці "Actions" вашого репозиторію.
6.  **Заповніть звіт** у файлі [`REPORT.md`](REPORT.md). Надайте відповіді на контрольні запитання та опишіть хід роботи.
7.  **Зробіть фінальний коміт** та переконайтесь, що всі тести пройшли успішно.

## Завдання для всіх варіантів

1.  **Вивчити основні концепції модульного тестування.** Що таке модульний тест? Які його переваги? Що таке тестовий випадок, тестовий набір, тестовий прибиральник (fixture)?
2.  **Ознайомитися з модулем `unittest`.** Як імпортувати модуль? Як створити клас, що наслідується від `unittest.TestCase`? Які основні методи перевірки (assertions) доступні в `unittest.TestCase`? Як організувати тести в методи класу? Як запустити тести?
3.  **Написати функцію або клас, що буде тестуватися.** Ця функція або клас повинна реалізовувати певний алгоритм або функціональність, описану у варіанті завдання.
4.  **Написати тестові випадки** для створеної функції або класу. Тести повинні покривати різні сценарії використання функції або класу, включаючи як очікувану поведінку, так і обробку помилок. Потрібно використати різноманітні методи перевірки для забезпечення ретельності тестування.
5.  **Організувати тести в тестові набори.** Згрупувати тести в логічні блоки для кращої організації та зручності запуску.
6.  **Запустити тести та проаналізувати результати.** Переконатися, що всі тести проходять успішно. У випадку помилок, проаналізувати вивід та виправити недоліки у коді або тестах.
7.  **Написати документацію до коду та тестів.** Забезпечити зрозумілість коду та тестів для інших розробників, використовуючи коментарі та рядки документації.

## Варіанти завдань

Оберіть один варіант для виконання.

1.  **Калькулятор.** Функції для додавання, віднімання, множення, ділення двох чисел. Тести для перевірки правильності операцій, обробки ділення на нуль.
2.  **Рядки.** Функція, що визначає, чи є рядок паліндромом. Тести для різних рядків, включаючи рядки з пробілами та різним регістром.
3.  **Списки.** Функція, що знаходить максимальний елемент у списку. Тести для різних списків, включаючи порожні та списки з однаковими елементами.
4.  **Словники.** Функція, що об’єднує два словники. Тести для різних словників, включаючи випадки з однаковими ключами.
5.  **Файли.** Функція, що читає файл та повертає кількість слів у ньому. Тести для файлів різного розміру та з різним вмістом.
6.  **Винятки.** Функція, що приймає на вхід число та повертає його квадратний корінь. Обробка винятків для нечислових вхідних даних.
7.  **Класи. Трикутник.** Клас, що представляє трикутник із методами для обчислення площі та периметра. Тести для різних типів трикутників.
8.  **Класи. Прямокутник.** Клас, що представляє прямокутник із методами для обчислення площі, периметра та перевірки, чи є він квадратом.
9.  **Сортування.** Функція, що сортує список чисел за зростанням. Тести для різних списків, включаючи вже відсортовані та у зворотньому порядку.
10. **Пошук.** Функція, що реалізує бінарний пошук у відсортованому списку. Тести для різних списків та шуканих значень, включаючи відсутні елементи.
11. **Матриці.** Функція, що транспонує матрицю (список списків). Тести для матриць різного розміру.
12. **Рекурсія.** Функція, що обчислює факторіал числа рекурсивно. Тести для різних значень, включаючи 0 та 1.
13. **Стек.** Клас, що реалізує стек з методами `push`, `pop` та `peek`. Тести для перевірки правильності роботи стеку.
14. **Черга.** Клас, що реалізує чергу з методами `enqueue`, `dequeue` та `peek`. Тести для перевірки правильності роботи черги.
15. **Дата і час.** Функція, що перевіряє, чи є заданий рік високосним. Тести для різних років.
16. **Геометрія.** Функція, що обчислює відстань між двома точками на площині. Тести для різних пар точок.
17. **Валідація.** Функція, що перевіряє, чи є заданий рядок коректною email-адресою. Тести для різних рядків.
18. **Користувач.** Клас, що представляє користувача з атрибутами (ім’я, прізвище, email) та методом для привітання. Тести на створення об’єктів та коректність привітання.
19. **Шифрування.** Функція, що реалізує шифр Цезаря. Тести для різних рядків та значень зсуву.
20. **Декоратори.** Написати декоратор, який вимірює час виконання функції. Написати функцію та застосувати до неї декоратор. Написати тести, які перевіряють, що функція повертає правильний результат.
21. **Контекстні менеджери.** Написати контекстний менеджер, який відкриває файл для запису та автоматично закриває його після виконання блоку коду. Написати тести для перевірки роботи менеджера.
22. **Генератори.** Написати генератор, який повертає послідовність чисел Фібоначчі. Написати тести для перевірки перших N чисел послідовності.
23. **Багатопотоковість.** Написати функцію, яка виконує довгу операцію (наприклад, чекає на відповідь від сервера). Запустити цю функцію в окремому потоці. Написати тести, які перевіряють, що функція виконується асинхронно.
24. **Модулі.** Створити власний модуль з декількома функціями. Написати тести для цих функцій в окремому файлі.
25. **Класи. Банківський рахунок.** Клас, що представляє банківський рахунок з методами для внесення та зняття коштів, а також перевірки балансу. Тести для перевірки правильності операцій.
26. **JSON.** Функція, що серіалізує об’єкт Python у JSON та десеріалізує JSON у об'єкт Python. Тести для різних об’єктів.
27. **Регулярні вирази.** Функція, що знаходить всі номери телефонів у тексті за допомогою регулярного виразу. Тести для різних текстів.
28. **Логування.** Додати логування до однієї з попередніх функцій/класів. Написати тести, які перевіряють, що події логуються правильно.
29. **Mocking.** Використати `unittest.mock` для заміни зовнішньої залежності (наприклад, виклику API) у тесті.
30. **Наслідування.** Створити базовий клас `Фігура` та похідні класи `Круг`, `Квадрат`, `Трикутник` з відповідними методами. Написати тести для перевірки поліморфізму.
31. **HTTP-запити.** Написати функцію, яка робить GET-запит до заданого URL та повертає код статусу відповіді. Написати тести, використовуючи `unittest.mock` для імітації відповіді сервера.
32. **Веб-скрапінг.** Написати функцію, яка збирає інформацію з веб-сторінки (наприклад, заголовки статей). Написати тести, які перевіряють правильність вилучення даних.
33. **Бази даних (SQLite).** Написати функції для створення таблиці, додавання, видалення та вибірки даних з бази даних SQLite. Написати тести для перевірки кожної функції.
34. **Асинхронне програмування.** Написати функцію з використанням `asyncio`, яка виконує кілька асинхронних завдань. Написати тести, використовуючи `asyncio.run` або `loop.run_until_complete`.
35. **Робота з датою та часом.** Написати функції для форматування дати та часу, обчислення різниці між датами, додавання/віднімання днів, місяців, років. Написати тести для кожного випадку.
36. **Обробка CSV.** Написати функції для читання та запису даних у CSV-файл. Написати тести для перевірки коректності обробки даних, включаючи випадки з різними роздільниками та лапками.
37. **Робота з XML.** Написати функції для парсингу XML-файлу та вилучення даних з певних тегів. Написати тести для перевірки правильності парсингу.
38. **Генерація випадкових даних.** Написати функцію для генерації випадкових чисел, рядків, списків, словників заданої структури. Написати тести, які перевіряють діапазон та розподіл згенерованих даних.

43. **Статичний аналіз коду.** Застосувати інструменти статичного аналізу коду (наприклад, `pylint` або `flake8`) до написаного коду та виправити знайдені помилки.
